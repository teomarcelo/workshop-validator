# Decision: Continue independent steps after HTTP 429

**Decided:** 2026-10-13
**Status:** Approved (Option A)

When a trial-org LLM gateway rate limit or similar environment limitation blocks an exercise step, the validator must mark that step unverified and queue bounded, rate-limit-compliant retries. Continue testing only steps that are independent of the blocked step and whose prerequisites are confirmed. Do not execute or mark downstream dependent steps as passed until the blocked step can be independently verified. If retries cannot resolve the blocker, report the overall run as incomplete and flag the step for review. Never treat an HTTP 429 as evidence that a guide is outdated.

This decision belongs in the living `PROJECT_PLAN.md` and should inform orchestration, QA gates, dependency handling, and error reports. Do not commit credentials, exercise guides, or private screenshots into this public repository.
